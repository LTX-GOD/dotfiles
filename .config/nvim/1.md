# Neovim 使用文档

## 基本信息

- **配置位置**: `/Users/zsm/.config/nvim/`
- **Leader 键**: `<Space>` (空格键)
- **本地 Leader 键**: `,` (逗号)

## 基础快捷键

### 模式切换

- `i` - 进入插入模式
- `v` - 进入可视模式
- `V` - 进入行可视模式
- `<C-v>` - 进入块可视模式
- `<Esc>` - 返回普通模式
- `:` - 进入命令模式

### 光标移动

- `h/j/k/l` - 左/下/上/右移动
- `w/b` - 按单词前进/后退
- `0/$` - 行首/行尾
- `gg/G` - 文件开头/结尾
- `<C-u>/<C-d>` - 向上/向下翻页

### 快速编辑操作

#### 删除操作

- `dd` - 删除当前行
- `dw` - 删除一个单词
- `d$` - 删除到行尾
- `d0` - 删除到行首
- `dG` - 删除到文件末尾
- `dgg` - 删除到文件开头
- `x` - 删除当前字符
- `X` - 删除前一个字符

#### 快速清空文件

- `ggdG` - **推荐方法**: 跳到文件开头并删除到末尾
- `ggVGd` - 全选后删除
- `:%d` - 使用命令删除所有行
- `<C-a>` 然后 `<Del>` - 全选删除（如果启用系统剪贴板）

#### 复制操作

- `yy` - 复制当前行
- `yw` - 复制一个单词
- `y$` - 复制到行尾
- `y0` - 复制到行首
- `yG` - 复制到文件末尾
- `ygg` - 复制到文件开头

#### 快速复制全部内容

- `:%y+` - **推荐方法**: 复制所有行到系统剪贴板
- `ggVGy` - 全选复制
- `gg"+yG` - 复制到系统剪贴板
- `ggyG` - 复制到文件末尾
- `ggVG"+y` - 全选复制到系统剪贴板

#### 粘贴操作

- `p` - 在光标后粘贴
- `P` - 在光标前粘贴
- `"+p` - 从系统剪贴板粘贴

#### 撤销和重做

- `u` - 撤销
- `<C-r>` - 重做
- `U` - 撤销整行更改

### 窗口管理

- `<C-w>h/j/k/l` - 在窗口间移动
- `<C-w>s` - 水平分割窗口
- `<C-w>v` - 垂直分割窗口
- `<C-w>q` - 关闭当前窗口
- `<C-w>=` - 平均分配窗口大小

### 标签页操作

- `gt` - 下一个标签页
- `gT` - 上一个标签页
- `<C-w>T` - 将当前窗口移到新标签页

### QuickFix 导航

- `]q` - 下一个 QuickFix 项目
- `[q` - 上一个 QuickFix 项目

## Leader 键快捷键组合

### 文件查找和导航 (Snacks)

- `<leader>ff` - 查找文件
- `<leader>fr` - 最近文件
- `<leader>fg` - 内容搜索
- `<leader>fh` - 帮助文档
- `<leader>fk` - 按键映射
- `<leader>fb` - 缓冲区
- `<leader>fm` - 标记
- `<leader>fn` - 通知
- `<leader>fs` - 工作区符号
- `<leader>fS` - 当前缓冲区符号
- `<leader>fi` - 图标
- `<leader>fl` - 行
- `<leader>fd` - 诊断
- `<leader>fH` - 高亮
- `<leader>fc` - Neovim 配置文件
- `<leader>f:` - 搜索历史
- `<leader>f;` - 跳转

### 缓冲区管理

- `<leader>bd` - 删除缓冲区
- `<leader>bo` - 删除其他缓冲区

- `<leader>ld` - 显示行诊断
- `<leader>td` - 切换诊断
- `<leader>th` - 切换内联提示

### 调试器 (DAP)

- `<leader>du` - 切换 DAP UI
- `<F5>` - 开始/继续调试
- `<F10>` - 步进
- `<F11>` - 步入
- `<F12>` - 步出
- `<leader>dc` - 关闭会话
- `<leader>dr` - 重启帧
- `<leader>dt` - 终止会话
- `<leader>dC` - 运行到光标
- `<leader>dR` - 切换 REPL
- `<leader>dh` - 悬停
- `<leader>db` - 设置断点
- `<leader>dB` - 清除断点

### Git 操作

- `<leader>gg` - 打开 Lazygit
- `<leader>gb` - Git blame

### 切换功能

- `<leader>tn` - 切换通知历史

### 多光标操作 (Multicursor)

- `<C-n>` - 添加/跳过光标
- `<leader>s` - 跳过当前匹配
- `<leader>N` - 添加光标（向上）
- `<leader>S` - 跳过当前匹配（向上）
- `<leader>A` - 添加所有匹配
- `<left>/<right>` - 旋转主光标
- `<c-leftmouse>` - 通过鼠标添加/移除光标
- `<c-q>` - 切换光标
- `<esc>` - 清除光标
- `<leader>gv` - 恢复光标
- `I/A` - 在可视选择中插入/追加
- `M` - 在可视选择中匹配光标
- `<c-i>/<c-o>` - 跳转列表支持

## 其他功能

### 文件操作

- `:e filename` - 打开/创建文件
- `:w` - 保存文件
- `:q` - 退出
- `:wq` - 保存并退出
- `:q!` - 强制退出不保存
- `:new` - 新建水平窗口
- `:vnew` - 新建垂直窗口
- `:tabnew` - 新建标签页

### 快速新建文件

- `:e filename.ext` - **推荐方法**: 创建并打开新文件
- `:new filename.ext` - 在新窗口创建文件
- `:vnew filename.ext` - 在垂直新窗口创建文件
- `:tabnew filename.ext` - 在新标签页创建文件
- `:e filename.ext | w` - 创建文件并立即保存

### 搜索和替换

- `/pattern` - 向前搜索
- `?pattern` - 向后搜索
- `n/N` - 下一个/上一个匹配
- `:%s/old/new/g` - 全局替换
- `:%s/old/new/gc` - 全局替换（确认）

### 终端操作

- `<C-\><C-n>` - 从终端模式返回普通模式
- `:terminal` - 打开终端

## 特定文件类型快捷键

### Markdown 文件

- `gx` - 打开 URL（在 Markdown 文件中）

## 插件功能

### 主要插件

- **Snacks.nvim** - 文件查找、缓冲区管理、通知等
- **Which-key** - 快捷键提示
- **Multicursor** - 多光标编辑
- **DAP** - 调试器
- **Render-markdown** - Markdown 预览（可通过 `:RenderMarkdown disable` 禁用）

### LSP 服务器支持

- **Lua**: lua_ls
- **Python**: basedpyright, pylsp, ruff
- **Go**: gopls
- **C/C++**: clangd
- **Markdown**: marksman
- **LaTeX**: texlab
- **Typst**: tinymist

## 使用技巧

1. **快速编辑**: 使用 `ggdG` 清空文件，`:%y+` 复制全部内容
2. **文件导航**: 使用 `<leader>ff` 快速查找文件
3. **代码跳转**: 使用 `gd` 跳转到定义，`gr` 查找引用
4. **多光标编辑**: 使用 `<C-n>` 选择多个相同单词进行批量编辑
5. **调试**: 使用 `<F5>` 开始调试，`<leader>db` 设置断点
6. **Git 操作**: 使用 `<leader>gg` 打开 Lazygit 进行版本控制

## 自定义配置位置

- **快捷键配置**: `~/.config/nvim/lua/custom/keymaps.lua`
- **插件配置**: `~/.config/nvim/lua/custom/plugins/`
- **LSP 配置**: `~/.config/nvim/lua/custom/lsp.lua`
- **选项配置**: `~/.config/nvim/lua/custom/options.lua`

---

**提示**: 使用 `:help` 命令可以查看更多帮助信息，使用 `<leader>fh` 可以快速搜索帮助文档。
