# AeroSpace 快捷键速查表（macOS）

> 本文整理自 AeroSpace 配置文件 `~/.aerospace.toml`，适用于 macOS 环境。  
> `Alt` 键即为 mac 键盘上的 `⌥ Option` 键喵～🐾

---

## 📐 窗口布局控制

| 快捷键           | 功能说明                         |
|------------------|----------------------------------|
| `Alt + /`        | 设置布局为 Tiles（横向优先）    |
| `Alt + ,`        | 设置布局为 Accordion（横向优先）|

---

## 🎯 窗口焦点切换

| 快捷键     | 功能说明       |
|------------|----------------|
| `Alt + H`  | 焦点移动到左边 |
| `Alt + J`  | 焦点移动到底部 |
| `Alt + K`  | 焦点移动到顶部 |
| `Alt + L`  | 焦点移动到右边 |

---

## 🚚 窗口移动

| 快捷键             | 功能说明         |
|--------------------|------------------|
| `Alt + Shift + H`  | 窗口移到左边     |
| `Alt + Shift + J`  | 窗口移到底部     |
| `Alt + Shift + K`  | 窗口移到顶部     |
| `Alt + Shift + L`  | 窗口移到右边     |
| `Alt + Cmd + Tab`  | 移动窗口并切换显示器焦点 |

---

## 📏 窗口缩放

| 快捷键                 | 功能说明       |
|------------------------|----------------|
| `Alt + Shift + -`      | 缩小窗口       |
| `Alt + Shift + =`      | 放大窗口       |

---

## 🧭 工作区切换

### 切换到工作区

| 快捷键     | 切换目标工作区 | 额外功能                     |
|------------|----------------|------------------------------|
| `Alt + 1~6`| 数字工作区     |                              |
| `Alt + 9`  | 工作区 9       |                              |
| `Alt + 0`  | 工作区 0       |                              |
| `Alt + B`  | 工作区 B       | Bilibili、音乐类应用         |
| `Alt + D`  | 工作区 D       | 文档类应用（如 Zotero）      |
| `Alt + G`  | 工作区 G       | 启动 ChatGPT 应用            |
| `Alt + P`  | 工作区 P       | 偏好设置类应用（系统设置等） |
| `Alt + Q`  | 工作区 Q       | 启动 QQ、WeChat、Discord 等  |
| `Alt + R`  | 工作区 R       | GTD 应用（Things、提醒事项等） |
| `Alt + Z`  | 工作区 Z       | Zoom 应用                     |

### 召唤工作区（overlay 弹出）

| 快捷键               | 功能说明         |
|----------------------|------------------|
| `Alt + Ctrl + 1~6`   | 召唤数字工作区   |
| `Alt + Ctrl + B/D/...` | 召唤字母工作区   |

### 移动窗口到工作区

| 快捷键                 | 功能说明                     |
|------------------------|------------------------------|
| `Alt + Shift + 1~6`    | 移动窗口到对应数字工作区     |
| `Alt + Shift + B/D/...`| 移动窗口到对应字母工作区     |

### 切换 & 移动整个工作区

| 快捷键           | 功能说明                 |
|------------------|--------------------------|
| `Alt + Tab`      | 在当前与上一个工作区切换 |
| `Alt + Shift + Tab` | 将整个工作区移到下一个显示器 |
