## Zsh

I use Zsh as my shell, and I utilize Zinit along with its plugins.

In comparison to Oh My Zsh, I believe Zinit is faster.

However, it doesn't have color highlighting after `ls`, so I sourced the `color.sh` script.

## Yazi

Yazi is the tool I use for browsing files in the terminal, and I've configured how most files are opened and compressed. I believe all terminal enthusiasts should give it a try.

![image](./attachments/251210-170920.avif)

## Kitty

Kitty is one of my favorite terminal emulators. It's written in multiple languages, which really suits my taste.

In particular, it supports image display with decent performance.

## Lazygit

Lazygit is my main tool for committing to GitHub, but its minor flaw is that it looks very messy with a large number of branches and merge records. At that point, maybe I will switch to using Git within VSCode?
